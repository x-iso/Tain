# Third-party licence texts

Verbatim licences for everything Tain **redistributes**. They are embedded into
the binary by [`tain-cli/src/gui/licenses.rs`](../tain-cli/src/gui/licenses.rs)
with `include_str!`, and shown in the app under **Settings → About → Licences…**.

Files here are *copies*, kept for dependencies whose licence is not already
somewhere in this repository. Where one is, `licenses.rs` points straight at it
instead, so it cannot drift:

| Already in the repo | Path |
|---|---|
| Tain (GPL-3.0-or-later) | [`LICENSE`](../LICENSE) — also the GPL text the LGPL builds on, so FFmpeg's entry uses it too |
| Virtual Display Driver | [`third_party/VirtualDisplayDriver/LICENSE`](../third_party/VirtualDisplayDriver/LICENSE) |
| FFmpeg (LGPL-3.0-or-later) | [`third_party/ffmpeg/COPYING.LGPLv3`](../third_party/ffmpeg/COPYING.LGPLv3), from the FFmpeg 7.1.5 release the DLLs are built from |
| Opus | [`third_party/ffmpeg/COPYING.libopus`](../third_party/ffmpeg/COPYING.libopus), from the libopus 1.6.1 release compiled into them |

Where a dependency offers a choice of licences (`MIT OR Apache-2.0`), the copy
here is the MIT option; `licenses.rs` still records the full choice in each
entry's `spdx` field.

## What is not reproduced in full

- **The ~440 smaller Rust crates.** `rust-crates.txt` lists every crate in the
  build with its version and declared licence. Their texts are in each crate's
  published source rather than copied here. All are permissive (MIT, Apache,
  BSD, ISC, Zlib, Unicode, BSL, CC0) or MPL-2.0.

The FFmpeg DLLs leave nothing out: libopus is the only library compiled into
them, and it has its own entry.

## Keeping this current

`include_str!` means a missing or renamed file is a **build error**, not a
silently dropped notice. What it cannot catch is a licence that changed
upstream, or a new dependency nobody added. So:

- **After anything changes `Cargo.lock`**, run `scripts/list-crate-licences.ps1`
  and commit `rust-crates.txt` with the change.
- **Adding a dependency that ships in the build and is worth naming**, add an
  entry to `licenses.rs`, a description key under `licences.` in every
  `i18n/*.lang`, and a copy here if its licence is not already in the repository.
- **Bumping one across a major version**, re-copy its licence and check the
  copyright line. Versions in the table above should be the version built.
- **Changing the FFmpeg build**, regenerate `ffmpeg-configuration.txt` from the
  configure line `scripts/build-ffmpeg.sh` prints, and update the versions in
  the FFmpeg and Opus entries' notes and in `third_party/ffmpeg/PROVENANCE.md`.
  The licence texts are copied in by the script, so they follow the build. A
  build without `--enable-version3` is LGPL-2.1-or-later and needs that text
  instead; one with `--enable-gpl` is compatible with Tain's licence but
  carries more notices.
- **Not needed** for build tools and build scripts, which are not redistributed.
